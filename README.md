## Run Locally

This repository contains a static portfolio website.

1. Clone the repository:
   ```bash
   git clone https://github.com/mohitmishra5782/portfolio.git
   cd portfolio
   ```
2. Open `index.html` in a browser, or start a local development server:
   ```bash
   python -m http.server 8000
   ```
3. Visit http://localhost:8000.
